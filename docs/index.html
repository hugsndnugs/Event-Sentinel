Welcome to Event Sentinel

Event Sentinel is a comprehensive Discord bot designed to help server administrators track and monitor all important events happening in their Discord servers. With beautiful, detailed embeds and extensive logging capabilities, you'll never miss an important event.

🔨

Moderation Events

Track bans, kicks, timeouts, and role changes with detailed moderator information.

🎙️

Voice Events

Monitor voice channel activity including joins, leaves, mutes, and moves.

📝

Message Events

Log message deletions and edits with full content preservation.

🧩

Channel Events

Track channel and thread creation, updates, and permission changes.

🎨

Role Events

Monitor role creation, deletion, and permission modifications.

Server Events

Keep track of server settings updates and invite management.
