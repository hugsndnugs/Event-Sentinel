Welcome to Event Sentinel

Event Sentinel is a comprehensive Discord bot designed to help server administrators track and monitor all important events happening in their Discord servers. With beautiful, detailed embeds and extensive logging capabilities, you'll never miss an important event.

📰 Latest News & Updates

June 2026

🔍 Richer Event Logs & Reliability Fixes!

Event logs now show what changed, where, and who did it, with permission diffs for channels and roles, before/after server settings, and clearer audit attribution across threads, voice, and messages. Reliability fixes address duplicate ban/leave logs, voice mute/deafen logging when join/leave is disabled, missing role change logs during busy activity, invite crashes on deleted channels, and channel permission edit crashes.

January 2026

⚡ Rate Limiting System & Utility Commands!

Event Sentinel now includes an advanced rate limiting system that automatically prevents Discord API rate limit errors. New utility commands like /ratelimitstatus, /botinfo, and /help make bot management easier than ever!

December 2025

📬 Modmail System Now Available!

Event Sentinel now includes a powerful modmail system! Allow users to contact your staff via DMs with automatic thread creation for organized support. Multi-guild support lets users select which server to contact. Configure it easily with /setmodmailchannel and /togglemail commands.

November 2025

Welcome to Event Sentinel Website!

We're excited to launch Event Sentinel's website - a comprehensive documentation for the bot.
