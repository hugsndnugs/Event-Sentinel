Developer Setup Instructions

This guide is for developers who want to host their own instance of Event Sentinel. If you're a Discord server administrator looking to use the bot, see the Getting Started guide instead.

👨‍💻 Developer Guide: This page covers hosting your own bot instance. End users should use the Getting Started guide to configure the bot in their servers.

💡 Prefer a Hosted Solution? You can use our hosted instance - invite Event Sentinel to your server without any setup!

1. Discord Bot Setup

  1. Go to Discord Developer Portal
  2. Click "New Application" and give it a name
  3. Go to the "Bot" section and click "Add Bot"
  4. Under "Privileged Gateway Intents", enable:
    • Presence Intent
    • Server Members Intent
    • Message Content Intent
    • Direct Messages Intent (required for modmail functionality)
  5. Copy your bot token (keep this secure!)

2. Bot Installation

Create Environment File

Create a .env file based on .env.example:

cp .env.example .env

Add Bot Token

Add your bot token to the .env file:

DISCORD_TOKEN=your_bot_token_here

Create Configuration Files

Choose one of the following configuration methods:

# For simple config (optional)
cp config.example.json config.json

# OR for modular config (recommended)
cp -r config.example config

Install Dependencies

Install required Python packages:

pip install discord.py python-dotenv PyNaCl

3. Invite Bot to Server

Generate an invite URL with the following permissions:

  • View Channels
  • Send Messages
  • Embed Links
  • Attach Files
  • Read Message History
  • View Audit Log
  • Manage Webhooks (optional)

Required scopes: bot, applications.commands

Invite URL template (replace YOUR_BOT_CLIENT_ID with your bot's client ID):

https://discord.com/api/oauth2/authorize?client_id=YOUR_BOT_CLIENT_ID&permissions=412385476672&scope=bot%20applications.commands

4. Configure Log Channel

Once the bot is running:

  1. Use the /setlogchannel command in your Discord server (must be an administrator)
  2. Select the channel where you want events to be logged for that specific server
  3. Make sure the bot has permission to send messages in that channel
  4. If you add the bot to multiple servers, repeat this command in each server to set up logging

Note: Each server has its own independent log channel configuration!

5. Running the Bot

Start the bot with:

python main.py

The bot will start and display:

  • Bot username and ID
  • Discord.py version
  • Current log channel (if configured)

Requirements

  • Python 3.11+
  • discord.py 2.4+
  • python-dotenv
  • PyNaCl

Permissions Required

The bot needs these permissions to function properly:

  • View Audit Log (to capture moderator information)
  • View Channels
  • Send Messages
  • Embed Links
  • Read Message History

Troubleshooting

If you encounter issues, check:

  • Bot has correct permissions in the server
  • All required intents are enabled in the Developer Portal (including Direct Messages Intent for modmail)
  • Log channel is properly configured with /setlogchannel
  • Bot has permission to send messages in the log channel
  • If using modmail, ensure the modmail channel has proper permissions (Send Messages, Embed Links, Create Public Threads, Send Messages in Threads)
  • Bot token is correct in the .env file
