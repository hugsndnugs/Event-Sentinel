## What is Event Sentinel?

Event Sentinel is a comprehensive Discord bot designed to help server administrators maintain detailed logs of all important server activities. Whether you need to track moderation actions, monitor voice channel activity, or keep records of message changes, Event Sentinel provides beautiful, organized event logs.

### Key Features

- 🔨 **Moderation Logging** - Track bans, kicks, timeouts, and role changes
- 🎙️ **Voice Activity** - Monitor voice channel joins, leaves, and muting
- 📝 **Message Tracking** - Log message deletions and edits with full context
- 🧩 **Channel Management** - Track channel and thread creation, updates, and deletions
- 🎨 **Role Monitoring** - Monitor role changes and permission updates
- ⚙️ **Server Events** - Log server setting changes and invite activity
