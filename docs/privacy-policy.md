# 🔒 Event Sentinel - Privacy Policy

**Last Updated:** October 24, 2025

## 1. Information Collected

Event Sentinel collects and stores only the minimum data required to function, including:

- Discord Server IDs  
- Log Channel IDs  
- Event details (such as message edits/deletions, moderation actions, etc.)  

No personal information (such as names, emails, or IP addresses) is collected or stored.

## 2. Data Usage

Collected data is used solely for:

- Logging server events  
- Maintaining configuration for each server  
- Debugging and improving performance  

## 3. Data Storage

All data is stored securely in local configuration files or the host environment. Data is **not shared**, **sold**, or **used for marketing**.

## 4. Data Retention & Deletion

Data is retained only as long as the bot is in your server. Removing the bot automatically removes access to your server's data.

To request manual data deletion, contact the developer via Discord: **HugsNdNugs**.

## 5. Third-Party Services

Event Sentinel interacts only with Discord's API. It does not send data to third-party services or external databases.

## 6. Security

All reasonable measures are taken to prevent unauthorized access or misuse of stored data.

## 7. Policy Updates

This Privacy Policy may be updated from time to time. Continued use of the bot after changes take effect implies acceptance of the new policy.
